# Tanmaiyee Allani, Personal Portfolio

Full Stack Development, Assignment 1. A responsive, accessible portfolio built with HTML5, CSS3, Bootstrap 5 and JavaScript (ES6+).

## Features
- Semantic sections: Home, About, Education, Skills, Projects, Achievements, Contact
- Mobile-first responsive layout (Bootstrap grid plus custom media queries)
- Project filter by category, rotating role text, scroll progress bar, scroll reveal
- Contact form with client-side validation and dynamic success and error alerts

## Run
Open `index.html` in a browser. No build step.

## Files
`index.html` holds the structure, styles and scripts. Add your own photo as `photo.jpg` in the same folder.
